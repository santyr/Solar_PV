# Retired Fullriver AGM System

> **Historical only. Do not apply these values or algorithms to the Discover
> AES bank.**

The retired bank used 16 Fullriver DC400-6 batteries in 8S2P, approximately
830 Ah nominal. Its defect investigation, voltage readings, dashboard, and
datasheet are retained as evidence.

Never reuse its Peukert correction, voltage-SOC curves, tail-current logic,
absorption/float settings, temperature compensation, or emergency safety-mode
configuration for the current lithium system.
